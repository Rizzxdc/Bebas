Python

Bahasa pemrograman yang ditulis hampir seperti kalimat biasa. Cocok untuk pemula, dipakai juga oleh para profesional.

# Program pertamamu
nama = "Dunia"
print(f"Halo, {nama}!")

Apa itu Python?

Python dibuat oleh Guido van Rossum dan pertama kali dirilis pada tahun 1991. Sintaksnya ringkas dan memakai indentasi untuk menandai blok kode, sehingga hasilnya rapi dan mudah dibaca.

Python berjalan di Windows, macOS, Linux, dan gratis untuk dipakai.

Dipakai untuk apa?

  • WebMembuat situs dan API dengan Django, Flask, atau FastAPI.
  • Data dan AIAnalisis data dan machine learning dengan pandas, NumPy, dan PyTorch.
  • OtomatisasiMengolah file, scraping, dan menjalankan tugas berulang secara otomatis.
  • Bot dan skripBot Telegram atau Discord dan alat bantu kecil untuk keperluan sehari-hari.

Contoh kode

Perulangan dan fungsi dalam Python terlihat seperti ini:

def sapa(nama):
    return f"Halo, {nama}!"

for teman in ["Ani", "Budi", "Citra"]:
    print(sapa(teman))

Cara mulai belajar

  1. Pasang Python dari python.org.
  2. Buka terminal lalu ketik python untuk mencoba kode langsung.
  3. Pelajari dasarnya: variabel, kondisi, perulangan, dan fungsi.
  4. Buat proyek kecil, misalnya kalkulator atau bot sederhana.
